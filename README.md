# Lista de tarefas

Uma aplicação simples para organizar tarefas do dia a dia, feita com HTML, CSS e JavaScript puro.

## Funcionalidades

- Adicionar e excluir tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas pendentes e concluídas
- Salvar a lista no armazenamento local do navegador

## Como executar

Abra `index.html` em um navegador. Não é necessário instalar dependências.
